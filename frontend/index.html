Structural Interaction Analysis

Analyze antibody–antigen interfaces from experimentally resolved protein structures. Resolves PDB coordinates, identifies antibody chains, maps IMGT CDR loops, calculates 5 Å intermolecular contacts, and computes cognate-pair CNN classification.

Computational Structural Pipeline

The automated pipeline transforms raw atomic 3D coordinates into a topological intramolecular contact representation for deep CNN inference.

01

PDB Structure

Resolves 3D atomic coordinates from local cache or RCSB PDB coordinate archives.

→
02

Chain Identification

Identifies antibody Heavy (H), Light (L), and protein Antigen (Ag) polymer chains.

→
03

CDR Mapping

Delineates canonical IMGT Complementarity Determining Regions (H1–H3, L1–L3).

→
04

5 Å Contact Graph

Calculates intermolecular heavy-atom distances (≤ 5.0 Å) to extract interface residues.

→
05

20×20 Matrix

Builds normalized intramolecular contact frequency representation in standard amino-acid order.

→
06

CNN Classification

Processes 20×21 tensor via trained CNN (199,681 parameters) to score cognate pairing.

• Scientific Reproducibility: Exact methodology of Zhang et al., BioSystems 243:105264 (2024).
• Input Support: Standard PDB format with antibody Heavy/Light chains and protein antigen chains.
